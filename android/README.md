# Android app

Abra esta pasta no Android Studio com JDK 17. O app é um protótipo com UI nativa Kotlin e conexão WebSocket.

- Emulador Android: `ws://10.0.2.2:8787`
- Dispositivo físico: `ws://IP_LOCAL_DO_PC:8787`
- Use o mesmo `BRIDGE_TOKEN` do servidor.
- Para uma versão de produção, remova cleartext traffic e configure `wss://` com TLS.
